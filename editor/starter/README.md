# Weaver starter

Lay out equal-width tiles on small or large viewports, distribute leftover pixels and map pointer coordinates back to an item.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Weaver** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
3
112
1
```

The vendor directory contains the framework source for 0.1.0 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/weaver) · [View the release](https://github.com/Rahulchaube1/blyx-weaver/releases/tag/v0.1.0)
